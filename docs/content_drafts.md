# 簡報內容設計草稿 (Content Drafts)

這個檔案用來記錄與討論簡報的新增投影片與內容設計草稿。


## 投影片草稿：為什麼客戶把真話藏在水面下？ (Why Motives Stay Hidden)

### 1. 設計目的與定位
- **目的**：承接前一頁「探尋來訪的真實動機」（表面動機 vs 真實場景）。上一頁點出「客戶說出口的往往只是表面動機」，本頁再往下追一層——**為什麼客戶不願意、甚至沒辦法一開始就講出真實動機？** 讓聽力師先理解背後的心理障礙，才不會急著推銷、才懂得先接住情緒、建立安全感，客戶才願意把水面下的真話說出來。這一頁是「觀察到有隱藏動機 →（本頁）理解為什麼隱藏 → 用病史詢問去挖掘」敘事鏈的中間那一環。
- **核心觀點：客戶藏起真實動機的四個原因**：
  1. **怕被貼標籤（污名）**：承認聽力損失、戴助聽器，等於承認「自己老了、退化了」。助聽器長年帶有「老人／殘障」的社會標籤，客戶下意識抗拒被這樣看待，於是把問題說小、說輕。
  2. **怕被推銷**：擔心一講出真實困擾，就會被業務抓住痛點猛推高價產品。於是先用「隨便看看」「醫生叫我來的」把自己武裝起來，觀察你值不值得信任。
  3. **放不下面子**：不想在家人面前顯得依賴、無能，長輩尤其怕成為家人的負擔，寧可淡化困擾，也不願承認「我需要幫忙」。
  4. **自己也沒察覺**：把「聽不清楚」歸因於「是別人講太小聲、環境太吵」，低估了聽損對生活的真實衝擊，常是被家人半推半就帶來的，所以根本講不出自己的真實動機。
- **定位**：置於「衛教與諮商」章節，插入於 `counseling-motivation`（探尋來訪的真實動機）之後、`counseling-history`（病史詢問）之前；`counseling-history` 及其後所有投影片依序順延一張。

### 2. 投影片結構與視覺排版：水面線比例版（v2，經 frontend-design 檢視後定案）
- **v2 定案理由**：原本規劃是「畫一座三角形冰山」，經設計檢視後修正——冰山真正有價值的只有「水面線」這個上下空間關係（線上＝說出口的、線下＝沒說出口的），這點編碼了真實內容必須保留；但「一座三角形冰山」有兩個問題要拿掉：(1) 它是管理簡報前三名的陳腔濫調，畫進這套乾淨 deck 容易變 clip-art、拉低質感；(2) 三角形會強加「越深＝越根本」的假排序，但污名／怕推銷／面子／沒察覺四個原因彼此**沒有深淺之分**，塞進尖三角等於捏造不存在的層級。**定案：留住「水面線＋上薄下厚比例」，拿掉三角形插畫。** 賭注下在比例（上窄下寬、深色壓場），而不是插畫。
- **簽名元素**：一條水面線 ＋ 刻意的 **約 15/85 上下比例**——上方「說出口的」窄到有點不安，下方深色水體壓場。整頁記憶點就這一個，其餘全部安靜、沿用 deck 既有語彙。這個版面跟第 5、6 頁的 tip-card、上一頁病史詢問的對話卡都明確區隔。
- **配色（全部取自現有 tokens，不新增顏色）**：
  - 日光層（水面上）：`#ffffff → #f5f8f1` 漸層（同 motivation 頁），字用 `color-text-heading`，呼應「攤在陽光下、可以說的」。
  - 水面線：`color-brand-primary-bright`（#99cb38 lime）→ `color-brand-accent`（#4eb3cf cyan）漸層線，線上／線下用小字標注「客戶說出口的 ↑ ／ 沒說出口的 ↓」。
  - 深水層（水面下）：`color-forest-900`（#455f51）底、白字；四個原因用**半透明白玻璃卡**（`rgba(255,255,255,0.08~0.12)`）浮在深色水體裡。
  - 強調卡：「怕被推銷」是最直接影響聽力師該怎麼應對的一點，用 `color-orange`（#ee7b08）強調這一張，其餘三張維持中性玻璃卡，避免四張同權重稀釋重點。
- **字體（deck 字體固定為正黑體，personality 靠字級落差而非字型）**：上方「說出口的」那句刻意做小（≈ body 24px、淺色、輕），下方「沒說出口的」區塊標籤做大，用大小對比講「說得少、藏得多」。
- **版面骨架（16:9）**：
  - 最上方：kicker「衛教與諮商」＋標題「客戶說出口的，只是冰山一角」（暫定；標題保留「冰山一角」成語當語言隱喻，但畫面不畫冰山）。
  - 日光層（窄，約 15%）：一句「說出口的」表面動機，可用一個小的提問泡泡呈現（例：💬「隨便看看，醫生叫我來的」），刻意小、靠上。
  - 水面線：橫貫整頁的漸層線＋上下標注。
  - 深水層（寬，約 85%）：2×2 四張玻璃卡，各卡＝小標（污名／怕推銷／面子／沒察覺）＋一句話說明。
  - 底部收尾：**不重用**第四頁的米色 `.impression-speed__twist` 卡（米色卡貼在深色水面上會像外貼的）；改成「直接畫在深水上、`color-brand-primary-bright` lime 左色條＋白字」的收尾句，與深色背景融為一體。

### 3. 逐步揭示機制 (Fragments)
- **預設狀態 (GSAP 進場)**：比照 `CounselingMotivationPage` 慣例，kicker（x: -28 / opacity: 0）→ 標題（y: 20 / opacity: 0）進場；水面線可用一段「由中央往兩側展開」或淡入的 GSAP 進場當視覺定錨。
- **Fragment 1**：日光層那句「說出口的」表面動機浮現（呼應上一頁，提醒「這些只是說出口的一角」）。
- **Fragment 2**：深水層四張「真實原因」玻璃卡整組揭示（一次整組，維持節奏俐落）。
- **Fragment 3**：深水上的 lime 左條收尾句出現。文案（暫定）：「客戶不是不說，是還沒覺得安全。別急著推銷——先讓他願意把水面下的話講出來。」
