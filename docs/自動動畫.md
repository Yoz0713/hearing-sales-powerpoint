# Reveal.js 自動動畫 (Auto-Animate) 導入與使用指南

Reveal.js 提供的 **Auto-Animate**（自動動畫）功能類似於 Keynote 的「魔術移動」(Magic Move)。它能夠自動偵測相鄰投影片中相同或相似的元素，並在切換投影片時，自動為這些元素的位置、大小、顏色及其他 CSS 屬性產生平滑的過渡動畫。

這份指南將協助你了解如何導入、使用並微調自動動畫。

---

## 1. 基本啟用方法

要啟用自動動畫，只需在相鄰的 `<section>`（投影片）標籤上加上 `data-auto-animate` 屬性。

```html
<section data-auto-animate>
  <h1>自動動畫</h1>
</section>
<section data-auto-animate>
  <h1 style="margin-top: 100px; color: #ff007f;">自動動畫</h1>
</section>
```

當簡報從第一張投影片切換到第二張時，標題 `<h1>` 會平滑地向下移動並改變顏色。

---

## 2. 元素匹配規則

Reveal.js 是透過以下規則來判斷哪些元素是「同一個元素」並進行動畫過渡：

1. **相同的 HTML 標籤與內容**：
   如果兩張投影片有相同的元素（例如相同的文字內容、相同的圖片路徑），Reveal.js 會自動匹配它們。
2. **使用 `data-id` 屬性（推薦）**：
   當元素內容改變（例如文字被修改、結構改變）時，自動匹配可能會失效。此時可以在元素上加上相同的 `data-id` 屬性來強行匹配。

### 範例：使用 `data-id` 來實現內容改變的動畫

```html
<section data-auto-animate>
  <div data-id="box" style="width: 100px; height: 100px; background: blue;"></div>
</section>
<section data-auto-animate>
  <!-- 雖然顏色和尺寸變了，但因為 data-id 相同，它會平滑過渡成紅色大方塊 -->
  <div data-id="box" style="width: 300px; height: 300px; background: red;"></div>
</section>
```

## 3. 常見應用範例

### 範例 A：程式碼區塊動畫 (Code Block Animate)
Auto-Animate 對於展示程式碼的演變非常有用。它會自動為程式碼的增加、刪除、修改加上動畫。

```html
<section data-auto-animate>
  <pre><code data-line-numbers data-trim data-noescape>
    function greet() {
      console.log("Hello");
    }
  </code></pre>
</section>
<section data-auto-animate>
  <pre><code data-line-numbers data-trim data-noescape>
    function greet(name) {
      console.log("Hello, " + name);
    }
  </code></pre>
</section>
```

### 範例 B：清單項目展開 (List Unveiling)
將清單的焦點逐一放大或改變不透明度。

```html
<section data-auto-animate>
  <ul>
    <li style="opacity: 1;">步驟一：下載套件</li>
    <li style="opacity: 0.2;">步驟二：初始化設定</li>
    <li style="opacity: 0.2;">步驟三：啟動開發伺服器</li>
  </ul>
</section>
<section data-auto-animate>
  <ul>
    <li style="opacity: 0.2;">步驟一：下載套件</li>
    <li style="opacity: 1; font-weight: bold;">步驟二：初始化設定</li>
    <li style="opacity: 0.2;">步驟三：啟動開發伺服器</li>
  </ul>
</section>
```

## 4. 進階設定選項

你可以在初始化 Reveal.js 時進行全域設定，或者在單一投影片上進行微調。

### 全域配置 (Vite / JS 中)
在初始化 Reveal.js 時，可以加入以下參數：

```javascript
Reveal.initialize({
  // 是否為沒有匹配到的元素加上淡入淡出動畫，預設為 true
  autoAnimateUnmatched: true,

  // 動畫的過渡曲線，預設為 'ease'
  autoAnimateEasing: 'ease',

  // 動畫持續時間（秒），預設為 1.0 秒
  autoAnimateDuration: 1.0,

  // 用來匹配的自訂屬性列表
  autoAnimateMatcher: null,
});
```

### 單張投影片微調 (Per-slide Overrides)
你可以使用 `data-auto-animate-*` 屬性，為特定投影片單獨設定動畫行為：

* `data-auto-animate-easing`：變更過渡曲線（例如 `linear`、`cubic-bezier(...)`）。
* `data-auto-animate-duration`：變更動畫時間（例如 `0.5` 代表半秒）。
* `data-auto-animate-restart`：強制中斷之前的自動動畫鏈結，即使上一張也是 auto-animate，也不會產生動畫。
* `data-auto-animate-delay`：延遲動畫開始的時間。

#### 範例：
```html
<section data-auto-animate data-auto-animate-duration="0.5" data-auto-animate-easing="ease-in-out">
  <h2 data-id="title">快速的過渡</h2>
</section>
```

## 5. 常見注意事項與 Tips

1. **維持層級結構**：
   如果一個元素在第一張投影片是 `<body>` 的直接子元素，但在第二張被包在了一個 `<div>` 裡面，自動動畫在計算位置時可能會有些微偏移。盡量保持相似的 DOM 層級結構。
2. **背景色與邊框**：
   對於顏色的過渡（如 `background-color` 或 `color`），必須確保兩邊都使用可識別的 CSS 顏色格式（例如 `#RRGGBB`、`rgb()` 或 `hsl()`）。
3. **避免過度使用**：
   自動動畫非常吸引眼球，但如果在每一頁都使用複雜的移動，會讓觀眾感到眼花撩亂。建議用於**核心概念演進、架構圖展開、或程式碼變更說明**。
