- 播放順序以 `src/presentation/slides.manifest.ts` 為唯一來源。

> [!info] 草稿頁的用途
> 草稿頁不是正式視覺成品。每頁固定呈現課綱位置、頁面目的、正式上屏內容、互動節奏與正式版方向，方便後續逐頁換成獨立正式元件。

## 後續正式化方式

1. 以 D 代碼選定要正式製作的頁面。
2. 從 `outline-draft.slides.ts` 取得已確認的標題、上屏文案、互動與視覺方向。
3. 在 `src/pages/` 建立正式 page component。
4. 只替換 `slides.manifest.ts` 中該頁的 `draft.*` 引用，保持 ID、章節及頁序穩定。
5. 正式頁完成後，從草稿 registry 移除對應規格。
